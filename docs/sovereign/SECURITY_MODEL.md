# Sovereign Security Model

- Sovereign exposes WhitePact power; it does not become authority.
- Simulations, shadow mode, capsules, and time machine comparisons are zero-effect.
- Tenant isolation enforced via `assert_same_organization` on repository reads.
- UNKNOWN outcomes are typed and must not be auto-retried by SDK clients.
- Gate B remains closed; dispatcher disabled; production closed in this build.
