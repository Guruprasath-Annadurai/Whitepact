# Sovereign CLI

Invoke via `whitepact sovereign ...` (BiasBuster commands remain under `whitepact run`).

Implemented V1 commands:

- `whitepact sovereign status`
- `whitepact sovereign version`
- `whitepact sovereign doctor`
- `whitepact sovereign ci`
- `whitepact sovereign manifest validate`
- `whitepact sovereign simulate blast-radius`

Use `--json` for machine output. No bypass flags.
