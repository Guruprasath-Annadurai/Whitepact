# Incident Response

1. Triage and contain (revoke grants, disable identity, rotate tokens).
2. Preserve audit correlation ids from admin grants.
3. Assess blast radius per provider.
4. Recovery per `10_DISASTER_RECOVERY.md`.
5. Post-incident: update `11_SECURITY_TEST_RESULTS.md` and regression tests.

Emergency paths documented for Cloudflare, IdP, WhitePact Cloud, and Hetzner outages.
