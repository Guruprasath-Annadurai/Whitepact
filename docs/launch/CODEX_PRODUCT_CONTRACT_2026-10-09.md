## What a visitor may be told

WhitePact is an independent runtime authorization boundary for AI agents. The agent may plan freely. Consequential execution is supposed to pass identity, authority, policy, approval when required, a short-lived grant, isolated execution, evidence, and revocation.

Supported engineering surfaces in this tree include the hosted MCP HTTP boundary, dashboard organization and policy APIs, Python SDK modules, and the Hetzner Terraform design. Community stdio is not enterprise-governed execution.
