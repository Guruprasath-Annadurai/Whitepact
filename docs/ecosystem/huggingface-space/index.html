WhitePact

Open-source runtime authorization and governance for autonomous AI agents. This page is a static explanation. It does not execute an agent, call a model, or connect to a hosted account.

The Python package to install is rai-governance-platform. On 2026-10-09 the newest release on PyPI was 1.2.6. Source version 1.3.1 was not that release. pip install whitepact is not the distribution.

What a governed decision can be

  • ALLOW
  • ALLOW_WITH_REDACTION
  • REQUIRE_APPROVAL
  • DENY
  • QUARANTINE

A denied decision does not receive an execution authorization. Requiring approval is not the same thing as executing the action. The repository example examples/ecosystem/runtime_authorization_demo.py exercises those paths locally.

Evaluate it yourself

pip install "rai-governance-platform[dashboard]==1.2.6"
