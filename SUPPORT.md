# Support

## Supported versions

WhitePact maintains one active release line. The latest published release receives
security and correctness fixes. Older releases may receive critical security fixes at
the maintainer's discretion; no long-term-support branch is currently offered.

## Where to ask

- Reproducible defects, feature requests, and documentation issues: use the public
  [issue tracker](https://github.com/Guruprasath-Annadurai/Whitepact/issues).
- Usage questions: use a GitHub issue with a minimal example and environment details.
- Suspected vulnerabilities: do **not** open a public issue; use the private channels
  in [SECURITY.md](SECURITY.md).

## Boundaries

Community support is best-effort and is not a contractual SLA. It does not include
customer deployment administration, legal or regulatory determinations, architecture
certification, provider approval, incident response for systems WhitePact does not
operate, or guarantees for unsupported forks and modified builds.

## Escalation and response

Security reports use the acknowledgement and triage targets in SECURITY.md. A public
issue that contains a credible vulnerability will be hidden or minimized where the
platform permits and moved to private advisory handling. Production incidents affecting
WhitePact-operated services follow the incident-response runbook.
