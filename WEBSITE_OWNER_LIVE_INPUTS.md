## Separate engineering contract dependency

The pinned SDK `get_evidence` / `getEvidence` detail helper targets an endpoint absent from that baseline. Backend/SDK owners must reconcile it before advertising it as a working detail example. `/docs` explicitly directs users to the supported organization-scoped evidence list or authenticated Evidence console. This website does not create a replacement endpoint or alter the SDK.

## Qualification boundary
